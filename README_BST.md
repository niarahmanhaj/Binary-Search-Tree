# Implementasi Binary Search Tree (BST) dengan Python

Proyek ini berisi tugas kuliah Struktur Data untuk mengimplementasikan **Binary Search Tree (BST)** secara murni menggunakan bahasa pemrograman Python. Kode ini mencakup operasi dasar pohon biner baik menggunakan pendekatan rekursif maupun iteratif.

## ✨ Fitur-Fitur
* **Penyisipan (Insert)**: Menambahkan node baru ke dalam pohon secara otomatis berdasarkan aturan BST (nilai lebih kecil di kiri, lebih besar di kanan).
* **Pencarian (Search)**: Mencari keberadaan suatu nilai di dalam pohon dengan efisien.
* **Penghapusan (Delete)**: Menghapus node dari pohon dengan menangani 3 kondisi (node tanpa anak, node dengan 1 anak, dan node dengan 2 anak).
* **Penelusuran (Tree Traversal)**: Dilengkapi dengan 3 metode cetak data:
  * Pre-Order (Root -> Kiri -> Kanan)
  * In-Order (Kiri -> Root -> Kanan) - *Menghasilkan data terurut naik*
  * Post-Order (Kiri -> Kanan -> Root)
* **Visualisasi Pohon**: Menampilkan struktur pohon secara horizontal di terminal menggunakan garis dahan (`└──`) agar posisi cabang kanan dan kiri terlihat jelas.

## 🚀 Cara Menjalankan
1. Pastikan Anda sudah menginstal Python di komputer Anda.
2. Jalankan file utama dengan perintah berikut di terminal:
   ```bash
   python "AVL Tree.py"
   ```
   *(Atau klik tombol Run kanan atas di VS Code).*
